- `00-Inbox/`：保存课堂原始记录；整理时保留原文。
- [`01-CSharp/`](01-CSharp/README.md)、`02-PLC/`、`03-Machine-Vision/`、`04-Industrial-Projects/`：存放经核对的主题笔记；C# 专题入口见 [C# 笔记索引](01-CSharp/README.md)。
- `05-Interview/`：跨主题面试复习资料。
- `06-Anki/`：按主题维护 UTF-8 CSV 卡片。
- `07-Study-Plan/`：学习路线、缺口与进度。
- `templates/`：新笔记模板。
- [待整理问题与课堂任务](todo.md)：原始学习记录，待学习、待核实；配图保存在 `assets/`。

新内容从 Inbox 开始；正式笔记标注掌握状态，AI 不会仅凭文档完整度推定你已掌握。详见 [维护规范](AGENTS.md) 和 [学习进度](07-Study-Plan/progress.md)。

第一次让 Codex 执行并生成 AGENTS.md 后，以后只需要发：
请遵循仓库 AGENTS.md 中的规则，扫描 00-Inbox 中尚未整理或更新的学习笔记，增量完善知识内容，补充适合 C# 工业机器视觉上位机岗位的面试题和 Anki 卡片，维护相关索引。保留原始笔记，避免重复修改已完善的内容。直接执行并汇报结果。

非常重要： Codex 可以帮你把笔记写得非常完整，但这不等于你真正掌握了知识。建议后续增加一个「模拟面试模式」：每周从你的笔记里抽取 15～20 道题，让你先回答，AI 再纠错，并根据你的表现更新复习优先级。
