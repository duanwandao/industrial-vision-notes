# P0 面试口述复习

> 待学习｜2026-10-31｜回答是学习参考，不能表述为已完成现场项目。

## C# 异步事件（Q013、Q016–018、Q056–059）

1. **P0：await 会创建线程吗？** 不会；它等待可等待对象并安排后续。同步耗时工作可交 Task.Run，异步 I/O 通常直接 await。
2. **P0：为什么事件用 async void，业务用 Task？** 事件签名要求 void；Task 让调用方等待并观察异常。async void 要在内部处理错误。
3. **P0：TCS 如何等待松开？** 按下创建 TCS，流程 await Task；松开等事件 TrySetResult。重复释放、提前释放和关闭都要考虑。
4. **P0：取消能停止已经写入的 PLC 指令吗？** 不能；取消是协作请求，已发送命令仍需协议停止和反馈。

## PLC 基础（Q005–009、Q020–023）

1. **P0：I/Q/M/V 分别是什么？** 输入映像、输出映像、内部标志和变量区；位含义由程序约定。
2. **P0：常闭接线就要用常闭梯形触点吗？** 不一定；接线决定电平，逻辑触点检查位值，先定义信号极性。
3. **P0：扫描周期影响什么？** 输入响应和逻辑更新时间；普通扫描可能漏掉短脉冲，高速输入按专用机制处理。

## 通信与类型（Q010–012、Q043–049）

1. **P0：ping 成功为何读不到 PLC？** ICMP 可达不证明 TCP 服务、协议、权限和地址正确；分层验证。
2. **P0：lock 是否让整个连接生命周期安全？** 只有共用同一锁的访问才互斥；连接/断开和长耗时也需统一考虑。
3. **P0：WriteFloat(addr,20) 会写 short 吗？** 仅 float 形参时转成 float；PLC 存储类型要另行约定，不能混写字宽。
4. **P0：结果对象和异常如何配合？** 先检查 IsSuccess 再取 Content，同时捕获异常并记录上下文。

## 运动控制（Q019、Q024–027、Q048、Q050–054）

1. **P0：细分越高精度必然越高吗？** 它提高指令分辨率，机械精度还受负载、误差和失步等影响。
2. **P0：200 ms 回零请求是否证明回零完成？** 不证明；需要 PLC 接受、运行、完成或故障反馈及超时。
3. **P0：限位、原点、急停各做什么？** 约束行程、建立坐标参考和执行紧急停止功能；普通 UI 不能替代安全设计。
4. **P0：Jog 松开写停止失败怎么办？** 报停止未确认并按设备停止规程处理；设计需有 PLC 失联策略和安全功能。

## 双轴源码（Q038–059）

1. **P0：attemptedStart 为什么在写 true 前设置？** 超时可能丢的是应答，实际已启动，仍要尝试复位。
2. **P0：为什么有按钮却不能认定功能完成？** 要追踪事件订阅到通信和 PLC 反馈；本提交停止/定位按钮未绑定。
3. **P0：FormClosing 释放 TCS 是否保证停止？** 不保证；当前未等待异步收尾，退出和网络都可能中断停止流程。
4. **P0：如何离线测 Jog？** 用假通信注入提前释放、启动超时、复位失败及关闭，检查调用序列和故障状态。



## 2026-11-02 新增现场面试题

1. **P0：什么是脉冲当量？** 一个有效指令脉冲对应的理论机械位移；直连丝杆按导程/每电机圈脉冲数计算。
2. **P0：导程和螺距一样吗？** 单头丝杆相同，多头丝杆导程=螺距×头数。
3. **P0：绝对定位为什么先建立零点？** 需要可信机械坐标参考；回零或可靠绝对位置反馈可建立。
4. **P0：回零中止后能继续用 HomeDone 吗？** 不能当成功，应明确中止并重新建立位置参考。
5. **P0：驱动器 S1–S3 / S4–S6 一定是什么？** 本次照片面板中前者配置细分、后者配置电流；不能推广所有驱动器。
6. **P0：运动控制卡和 PLC 运动控制区别？** 板卡/控制器专门处理实时运动，PLC 通常还处理工艺逻辑；能力看具体型号。
7. **P0：怎么查实时梯形图？** 确认 CPU/工程匹配，在线开启程序状态；状态图读变量，短脉冲可能被刷新遗漏。
8. **P0：量程换算公式？** 工程下限+(输入−输入下限)/(输入上限−输入下限)×工程跨度。
9. **P1：PLC 四大硬件部分与 MCU 关系？** CPU、存储器、I/O、电源；MCU 是芯片，PLC 是工业设备。
10. **P1：脉冲当量 0.0005 mm 就有 0.5 μm 精度吗？** 不保证；还受失步、导程误差、背隙和负载等影响。

## 2026-11-03 PLC 扫描、梯形图与握手复习

1. **P0：什么是输入映像区？** CPU 在扫描开始时采样数字量物理输入并保存为 I 区快照，用户程序通常读取这份快照；Q 输出映像在扫描末刷新到物理输出，M 是内部标志区。
2. **P0：物理常闭停止按钮为什么常配梯形图常开触点？** 在约定的 NC 输入回路中，正常时 I0.1=1，断开/按下时 I0.1=0；梯形图常开触点检查 I0.1 是否为 1，表达“停止回路健康才允许运行”。物理接点和逻辑触点不是一一对应。
3. **P0：P 与 N 触点的区别？** P 检测逻辑 0→1，N 检测 1→0；检测结果通常只成立一个扫描周期，不能代替高速脉冲捕捉。
4. **P1：S7-200 SMART 的 STL 是什么？** Statement List（语句表），用 LD、A、O、EU、ED、S、R 等助记符和参数描述逻辑；不要与 C++ STL 或结构化文本 ST 混淆。
5. **P0：普通线圈和 S/R 有什么区别？** 普通线圈每次扫描根据当前逻辑条件更新目标位；S 在条件成立时置 1 并保持，R 在条件成立时清 0 并保持，直到相反操作。
6. **P0：自锁逻辑怎么表达？** 停止回路正常 AND（启动按钮 OR 当前运行状态），即 Run = StopHealthy && (Start || Run)；自身运行位触点并联在启动支路上。
7. **P0：软件互锁和硬件互锁有什么区别？** 软件互锁由 PLC 逻辑禁止冲突命令；硬件互锁由辅助触点/机械结构等在电气层限制冲突动作。普通互锁不自动构成安全功能。
8. **P0：为什么视觉检测不能只用 20 ms 短暂置位 Trigger？** PLC 扫描或 PC 轮询可能错过短脉冲；请求应保持直到接收确认，结果保持直到 PLC 确认。
9. **P0：TriggerAck 与 ResultAck 分别代表什么？** TriggerAck 表示上位机接受了请求；ResultAck 表示 PLC 已消费结果。它们不是同一个确认阶段。
10. **P0：HslCommunication 写入成功是否等于检测完成？** 不等于；写成功只是通信层结果，仍需 PLC 应用层状态、RequestId/ResultId 和 Done/ResultAck 握手。


## 2026-11-03 电学基础口述复习

1. **P0：什么是电场？电场方向如何规定？** 电场是能对电荷施加电场力的物理场；某点电场方向按正试探电荷受力方向定义。
2. **P0：电场和电压有什么区别？** 电场描述每个位置的受力情况，电压是两点之间的电势差；前者是空间矢量场，后者是两点间的标量差。
3. **P0：电场怎样影响金属导线中的电子？** 电子带负电，受力方向与电场相反；电子发生定向漂移，形成电流，约定电流方向与电子漂移方向相反。
4. **P0：欧姆定律 U=IR 是否适用于所有元件？** 不适用于所有元件；它适用于满足欧姆特性的元件，并需考虑温度等条件。
5. **P0：断路时为什么可能有电压却没有持续电流？** 电压是两点电势差；断路使持续电流回路中断，但电源两端仍可保持电势差。
6. **P0：PLC 的 24V DC 输入意味着有 24V 电流吗？** 不对，24V 表示两点间电势差；输入电流由输入电路、传感器输出方式和模块规格决定，应查接线图与手册。

详见[电学基础](../02-PLC/Electrical-Fundamentals.md)。以上为基础原理复习，不代表已经完成实机测量或接线验证。


## 2026-11-04 工业电气、PLC 输入与变频器口述复习

1. **P0：为什么工业 24V 多负载通常并联，选电源为何电流相加？** 每台要得到额定 24V，通常接在同一 +24V/0V 两端；电源总电流为同时工作的各支路电流之和，按最大同时负载和余量设计。
2. **P0：额定 24V/5A 电源带持续需要 6A 的负载会怎样？** 已超过额定能力，可能限流、掉压或停机，不能保证稳定运行，需查过载能力及负载工况。
3. **P0：为什么 0V 端子仍可能有电流？** 电位是相对参考点的量，电流是穿过截面的电荷速率；回到 0V 的支路仍可承载与串联回路相同的电流。
4. **P0：NPN 输出把 I0.0 拉向 0V，PLC 为什么读 1？** 对支持 NPN 的输入组，COM 接 +24V，电流经输入检测电路、I0.0、NPN 开关返回 0V，达到有效输入条件后逻辑位为 1。
5. **P0：PNP 与 NPN、COM 接法有什么区别？** PNP 动作常向信号端提供 +24V，输入 COM 接 0V；NPN 动作常拉信号端到 0V，兼容输入 COM 接 +24V，具体查型号。
6. **P0：光耦做什么，为什么不能说 LED 发光=CPU 引脚高电平？** 光耦通过光传状态并提供规定的电气隔离；后级上拉/反相电路决定高低逻辑，内部物理电平和 I 位不同层。
7. **P0：限流电阻是如何保护 LED 的？** 用串联压降限制整回路电流，并消耗相应热功率；必须核对 LED 和电阻额定值。
8. **P0：固定 24V 下 100Ω 换 200Ω，电流及发热功率如何变化？** 分别由 0.24A/5.76W 变为 0.12A/2.88W；固定电压下电阻增大使两者减小。
9. **P0：短路与过载有何区别？** 短路是异常低阻抗路径；过载是在正常路径中超过线路/设备的允许电流，保护方式依具体曲线和配置。
10. **P0：RCCB 与 RCBO 区别，PE 什么时候起作用？** RCCB 只提供剩余电流保护，RCBO 还含过流保护；PE 连外露导电部分，绝缘故障时为故障电流与自动切断提供条件，本身不主动跳闸。
11. **P0：为什么 24V 支路短路可能不让断路器快速跳闸，还使 PLC 重启？** 开关电源限流可能让故障电流不足以触发下游磁脱扣而总线掉压，需协调分路保护。
12. **P1：4 极电机在 50Hz 下同步转速多少？逆变器与 VFD 关系？** 4 极=2 对极，同步转速 1500r/min；逆变器是把 DC 变 AC 的功率级，常见 VFD 由整流、直流母线、逆变及控制保护组成。

## 2026-11-04 三相交流、电容、继电器与接触器

1. **P0：交流电流为什么会出现负值？** 正负是相对于选定参考方向的符号；−5A 表示大小 5A、方向与规定正方向相反，不代表没有电流。
2. **P0：50Hz 交流电的周期和过零次数是多少？** 周期 20ms；理想正弦电压每周期过零两次，即每秒 100 次。过零是瞬时值为零，不是断电。
3. **P0：220V 交流电是峰值还是有效值？** 通常是有效值；理想正弦波峰值约 311V。230V 有效值对应峰值约 325V。
4. **P0：电热丝为什么在交流正、负半周都发热？** 纯电阻负载中电压和电流同时反向，p=ui=i²R≥0；热量不会因电流负号抵消。
5. **P0：电容储存什么，储能公式是什么？** 能量储存在两极板间电场中；Q=CU，E=½CU²。理想电容的电流 i=C·du/dt。
6. **P0：理想电容接稳定直流很久后，为什么没有持续电流？** 充电完成后电压不再变化，du/dt=0，因此 i=0；真实电容仍可能有漏电流。
7. **P0：平衡三相电流为什么不需要中性线电流？** 三相电流相差 120°，同一时刻瞬时电流代数和为零；平衡正弦负载的中性线电流为零。
8. **P0：三相三线电机为什么不需要 N？** 三相绕组在相线之间构成工作回路；星形电机的星点可不引出，三角形绕组形成闭合回路。PE 仍需保护连接。
9. **P0：三相电机运行中缺相会怎样？** 可能继续转动但转矩下降、剩余相电流不平衡并过热；静止时通常不能正常自启动。具体依电机、接法和负载。
10. **P0：三相 RCD 如何检测剩余电流？** 所有工作导体（L1/L2/L3，若有 N 也包括 N）穿过同一检测磁芯，检测电流瞬时代数和；PE 不作为工作导体穿过该磁芯。
11. **P0：继电器/接触器为什么能用小控制信号控制大功率负载？** 小电流给线圈供电产生磁力，驱动机械触点；负载能量来自独立主电源，不是线圈放大电能。
12. **P0：接触器 A1/A2 与 L1/L2/L3、T1/T2/T3 分别是什么？** A1/A2 是线圈端；L/T 通常是主触点进/出线端，具体标记看型号。
13. **P0：PLC Q0.0=1，为什么不能认定接触器已吸合？** 逻辑命令、物理输出、线圈得电、接触器辅助反馈和电机实际运行是不同层次，必须有对应反馈。
14. **P0：A1/A2 测得 0V 时优先排查什么？** 控制电源、输出模块及公共端、保险/联锁、接线和输出类型；0V 本身不能证明接触器机械卡滞。
15. **P0：热过载复位后为什么不能无条件自动启动？** 故障原因可能未排除，突然启动有人员和设备风险；复位与新的启动命令应分开，并按风险评估设计。
