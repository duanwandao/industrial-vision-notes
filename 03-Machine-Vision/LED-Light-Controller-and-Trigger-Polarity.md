## 1. 光源控制器在视觉系统中的位置

LED 光源控制器负责按设定驱动 LED 光源，并可能接收 PLC、相机或其他控制器发来的外部触发信号。典型视觉系统中：

- 工业相机负责曝光和图像采集。
- LED 光源负责照亮被测物。
- LED 控制器负责光源通道、亮度及其输出/触发行为。
- PLC 负责设备顺序、到位条件和硬件 I/O。
- C# 上位机负责配置、流程编排、状态监控、图像处理和结果追溯。

C# 发出“开始采集”并不意味着 Windows 软件线程应逐帧控制微秒级闪光；严格时序应交给相机 I/O、光源控制器、PLC/运动控制器或专用触发硬件。

## 3. 不要混淆 CH1、TR1、触发模式和触发极性

### CH 与 TR 通常承担不同职责

- **CH1 / CH2：** 面板上的光源输出通道标识，负责向对应 LED 光源提供受控输出。准确额定值和通道映射以手册为准。
- **TR1 / TR2：** 外部触发输入端标识，用于接收控制信号；它不是 LED 电源输出端。
- **COM：** 常见含义是公共参考/公共端，但必须确认该控制器端子图，不能假设它必然是 0V 或可直接与任意 PLC COM 相连。

可先用功能图理解（不是实机接线图）：

\`\`\`
PLC / 相机数字输出 ──> 控制器触发输入 TR1
                              │
                              ▼
控制器按模式与参数决定是否驱动
                              │
                              ▼
                         CH1 光源输出 ──> LED
\`\`\`

### 三个独立概念

1. **常亮 / 外部触发：** 决定光源是否持续输出，还是等待外部信号。
2. **电平触发 / 边沿触发：** 电平跟随通常在有效电平持续期间输出；边沿触发通常在指定边沿到来时启动一次脉冲。
3. **Active High / Active Low：** 决定高电平还是低电平被识别为有效状态。

这三个维度不能混为一谈。一个面板上的 HIGH/LOW 开关不一定只代表触发极性，必须查 CCD500 对应说明书。

### 为什么 LOW 后灯亮，仍不能直接下结论？

若 LOW 被手册定义为低电平有效，那么当前 TR1 输入可能处于有效低电平；但也可能是 LOW 选择了常亮/其他输出逻辑，或输入端悬空/偏置状态被控制器解释为有效。没有型号手册、TR1-COM 接线和电压测量，无法在这些解释之间定论。

## 4. Q1.2 指示灯与真实电气电平不是一回事

S7-200 SMART 的 Q1.2 是输出映像区的一个位地址（Q 字节 1 的第 2 位）。在线监控的逻辑位、CPU 面板指示灯、输出端子实际电压和外部设备识别到的触发状态，是不同层次。

- Q1.2 指示灯未亮，通常表示该输出点当时没有处于激活状态。
- **ST 晶体管输出：** 输出关断时晶体管通常截止，输出端可能呈断开/高阻状态；不能一概称为主动输出 0V。
- **SR 继电器输出：** 输出关断时继电器触点通常断开；触点两端电压取决于外部回路，不是 PLC 主动产生的固定 0V。
- TR1 的实际电位必须相对于控制器规定的参考端测量，并结合 PLC 输出类型、公共端和完整回路判断。

因此，“Q1.2 灯没亮”只能作为 PLC 输出状态的一条证据，不能单独证明 TR1 收到低电平。

S7-200 SMART 的型号命名也要读完整：标准型中，S 表示 Standard 系列；第二个字母 T 表示 DC 电源/直流晶体管输出，R 表示 AC 电源/继电器输出；数字表示本体数字 I/O 点数。具体输出接线和电气额定值仍须按完整订货号手册确认。参见 Siemens 系统手册。

## 5. 安全的现场排查顺序

1. 先拍清楚 CCD500 铭牌、端子标签、光源连接器和控制器背面型号；查到对应手册后再解释 HIGH/LOW。
2. 沿 CH1 光源线追踪到 LED 本体，确认连接器插接、通道和光源额定值匹配；不要因为光源没有独立电源线就假定它一定已由 CH1 正确供电。
3. 确认 TR1 与 COM 的端子定义、通道映射及输入电气规格。
4. 在线监控 PLC 程序中的 Q1.2 逻辑状态，并核对实际输出模块型号和公共端接线。
5. 在老师许可、设备处于安全状态且不会引起危险动作时，按设备规程观察 Q1.2 的受控变化；由受训人员使用合适仪表测量 TR1 相对指定 COM 的信号。
6. 分别验证控制器逻辑输出与 LED 实际发光。需要精确频闪时，可使用合适的示波器和光电二极管测量实际光脉冲。
7. 记录每次测试的模式、Q1.2 状态、TR1 电平、LED 亮灭和相机图像，不要一次改多个参数。

**禁止做法：** 未查手册就短接 TR1 与 COM、向触发端直接送 24V、把 COM 当作 0V、带电插拔光源或绕过设备安全联锁。软件逻辑和普通 PLC 输出不能替代急停及安全回路。

## 6. 与相机曝光/频闪同步的关系

若使用外部触发频闪，目标是让 LED 的实际发光窗口与相机有效曝光窗口按预期重叠。相机 Exposure Active 输出可以在部分型号上作为光源触发源，但要确认相机输出规格、光源输入规格、有效极性和延迟。仅仅让 PLC 同时置位相机和光源两路输出，并不能保证实际曝光与发光同步。

详细时序见[相机曝光与 LED 光源频闪同步](Exposure-and-Light-Source-Strobe-Synchronization.md)。
