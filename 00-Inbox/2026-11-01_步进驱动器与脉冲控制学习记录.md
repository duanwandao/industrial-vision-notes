# 2026-11-01｜步进驱动器与脉冲控制学习记录（原始输入摘要）

> 来源：2026-11-01 与 ChatGPT 的学习对话及用户上传的两张实训台照片。此文件记录用户问题和照片可见标识；解释性知识整理见 `02-PLC/Motion-Control.md`。

## 用户提出的问题

- 什么是驱动器和电机？
- 什么是脉冲？
- 什么是电平？
- 什么是步进驱动器？为什么 PLC 输出 1000 个脉冲，步进电机就能转动指定角度？驱动器内部究竟做了什么？
- 用户的初步理解：“说白了有脉冲电机才会动，有点像一次高电平其实就是通一下电？”需要进一步区分逻辑控制脉冲与电机绕组动力电流。

## 用户上传照片中可见的标识

- 控制柜中有两台贴有“步进驱动1”“步进驱动2”标签的黑色设备。
- 一台设备特写可见 `ENA- / ENA+`、`DIR- / DIR+`、`PUL- / PUL+`。
- 可见 `B- / B+`、`A- / A+`、`GND`、`VCC` 标识。
- 面板印有 `DC: 9~42VDC`。
- 细分表可见 1、2/A、2/B、4、8、16、32 档及每圈脉冲数；8 档标注 1600 pulse/rev。
- 面板另有 `Current(A) / PKCurrent` 与 S4–S6 电流档位表。

## 待核实事项

- 驱动器完整型号与说明书。
- 电机铭牌、步距角、额定相电流。
- S1–S6 当前实际拨码状态。
- PLC 型号、PTO 通道、实际脉冲/方向输出地址和输出电气类型。
- 驱动器与 PLC 的实际接线、有效电平、输入时序、ENA 行为。
- `VCC / GND` 的确切电源定义与接线。
