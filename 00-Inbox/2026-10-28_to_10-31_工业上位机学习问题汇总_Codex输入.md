### 2. `PlcHelper`：连接检查 + lock + 结果对象

```csharp
private readonly object sync = new object();

public OperateResult<bool> ReadBool(string address)
{
    lock (sync)
    {
        if (!isConnect || plc == null)
            return new OperateResult<bool>
            {
                IsSuccess = false,
                Message = "PLC 未连接"
            };
        return plc.ReadBool(address);
    }
}

public OperateResult<float> ReadFloat(string address)
{
    lock (sync)
    {
        if (!isConnect || plc == null)
            return new OperateResult<float>
            {
                IsSuccess = false,
                Message = "PLC 未连接"
            };
        return plc.ReadFloat(address);
    }
}
```

**待解释**：`isConnect` 并不等于实时在线；`lock` 的范围和可能导致的 UI 阻塞；`OperateResult<T>`；提炼 `Execute<T>` 的收益和潜在复杂度；连接/断开同样要考虑互斥。`SiemensS7Net` 和示例 IP/端口请以实际项目为准。
