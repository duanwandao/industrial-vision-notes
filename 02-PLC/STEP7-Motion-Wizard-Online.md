## 如何打开运动控制向导

在 STEP 7-Micro/WIN SMART 左侧项目树展开 **向导 → 运动**，通常双击打开运动控制向导。向导可能包含各轴设置、轴组、映射与完成页；不同 CPU、软件版本、输出模式显示项可能不同。截图是只读 `.smart` 项目，若要修改应先另存副本；任何实际下载需老师/现场授权。

### 截图「映射」页看到了什么

| 轴 | 功能 | 地址（**截图显示，非现场确认**） |
|---|---|---|
| 轴0 | LMT+ / LMT- / RPS | I0.4 / I0.2 / I0.3 |
| 轴0 | P0 / P1 | Q0.0 / Q0.2 |
| 轴1 | LMT+ / LMT- / RPS | I0.7 / I0.5 / I0.6 |
| 轴1 | P0 / P1 | Q0.1 / Q0.7 |
| 轴2 | P0 / P1 | Q0.3 / Q1.0 |

`LMT+`、`LMT-` 一般为正/负向限位输入，`RPS` 为参考点输入；`P0/P1` 是运动输出映射，**各自究竟是脉冲还是方向需结合向导的脉冲输出模式核对**，不能无条件等同 PUL/DIR。逻辑地址映射也不等于已核对真实导线接线。

## 梯形图截图「步进轴1」与 GOTO

截图包含：`Always_On` 触点使能运动块；`M1.1` 后接 `P` 正跳变触点作为启动事件；运动块名称在画面被截断（结合接口可推测为 `AXIS1_GOTO`，需在软件中确认完整名称）。

| 截图端口 | 截图参数 | 用途（按轴 GOTO 常见接口理解） |
|---|---|---|
| EN | Always_On | 每个扫描周期调用/使能 |
| STA~ | M1.1 经 P | 上升沿启动请求 |
| Pos | VD3008 | 位置参数，数据类型及工程单位看指令和轴配置 |
| Spe~ | VD3012 | 速度参数，工程单位看配置 |
| Mode | 0 | 可能为绝对定位模式；以软件当前指令帮助定义为准 |
| Abort | 符号「急停」 | 运动命令中止输入，**不是安全急停回路** |
| Done | V0.6 | 运动指令完成信号 |
| Error | VB16 | 指令错误状态/代码 |

注意：`VD3008` 不必然是 REAL，也不必然是 mm；`V0.6` 在 SMART 中是 V 区字节 0 第 6 位，而 `VB16` 是一个字节。要到**符号表、指令帮助和运动向导**核对类型、单位、模式、状态与错误码；不要凭截图直接写入生产 PLC。

### 为什么用 P 上升沿？

`P` 在检测到前一级逻辑由 0→1 时仅在一个扫描周期导通，便于把持续置位的请求变成单次启动事件。PLC 扫描太慢或写位窗口太短时可能漏检；可用请求/应答握手或命令序号设计更可靠的控制流程。

## 如何查看实时状态

**方式 A：程序状态**：确认正确的 CPU、项目版本和在线通信；打开相关梯形图，使用软件菜单「调试」中的程序状态/在线监视功能（具体名称随版本界面变化），观察触点通断、块状态和变量实时值。监视的是在线 CPU 状态，不是本地文件的模拟运行。不能单凭本地工程编译成功确认在线版本一致。

**方式 B：状态图（Status Chart）**：从左侧「状态图」创建/打开监控表，添加目标地址，按正确类型监控值。适合观察 `M1.1`、`VD3008`、`VD3012`、`V0.6`、`VB16`；短扫描周期上升沿可能在普通刷新周期内看不到，需用 PLC 侧诊断位/计数或事件记录。

**只读观察优先**：不要用强制（Force）、写入（Write）、切换 RUN/STOP 或下载（Download）来“试监控”。监控前核对 PLC 的 IP、现场身份、运行许可与机械安全；修改输出或 RUN 可能造成电机意外运动。
