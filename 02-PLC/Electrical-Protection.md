# 短路、过载、PE、断路器、熔断器与漏电保护

> P0｜学习中 / 待验证｜2026-11-04。仅作电气原理与故障思路学习，**不是电柜设计、保护定值或带电调试指令**。

## 1. 短路和过载不是同一个故障

- **短路**：不该直接相连的不同电位点经低阻抗路径连通，故障电流可能迅速增大；实际大小还受电源内部阻抗、限流与线路阻抗限制。
- **过载**：电流沿着正常负载路径流动，但持续或瞬时超过某段线路/元件的允许能力，例如多设备同时启用、机械负载过大。
- 导线发热近似 `P=I²R`。在导线电阻不变时，电流翻倍，发热功率四倍。安全取决于温升、时间、敷设、绝缘、保护设备等，不只看瞬时功率。

## 2. 常见小型断路器（MCB，俗称空气开关）

常见热磁式 MCB 含：
- 热脱扣：双金属片加热弯曲，主要用于持续过载；过载程度影响动作时间（反时限）。
- 磁脱扣：很大故障电流使电磁机构快速动作，主要用于严重短路。

额定 16A 不意味着在 16.01A 时立即跳闸；需要看产品脱扣曲线、标准和现场工况。B/C 等脱扣曲线与瞬时动作阈值相关，**不能单凭「16A」推断启动电流是否合适**。选型要满足回路电压、AC/DC 适用性、分断能力、配线与保护配合。

## 3. 熔断器（Fuse）

熔芯在过电流达到相应能量/时间后熔断，切断故障回路；通常需更换。不能笼统断定熔断器一定比断路器快，需比较实际型号的时间—电流曲线与分断能力。不能自行用铜丝代替熔芯。

## 4. PE（Protective Earth）什么时候起作用？

- **PE** 是保护接地导体，连接需要保护的外露可导电外壳等；正常工作通常不承载设备的工作回流电流，持续承担等电位连接功能。
- **N** 是交流中性线；**0V** 是直流控制电源参考端；不能把 `PE / N / 0V` 当作同一根线。
- 当绝缘故障让火线接触金属外壳，PE 和供电接地系统提供故障回路，使合适的保护装置有机会及时自动切断。
- PE 自身**不是会检测并切断电源的开关**；故障回路阻抗、接地方式和保护协调决定断电效果。

## 5. 漏电保护（RCD）的判断机制

RCD（Residual Current Device）比较穿过其检测回路的各工作导体的电流矢量和。单相典型为 L 与 N 的回流不平衡：如 L 5.00A、N 4.95A，剩余电流约 0.05A = 50mA。满足相应 RCD 规格的动作条件时切断电源。

- **RCCB**：剩余电流保护，不自带过电流保护，须与合适的过流保护协调。
- **RCBO**：同时具有剩余电流和过电流保护。
- RCD 不以 PE 作为检测前提，PE 仍是独立重要的保护措施。
- 人同时接触 L 与 N 且电流平衡时，RCD 可能不动作；**绝不能视作绝对防触电**。
- 30mA RCD 常用于人身触电附加保护，但不能替代基本绝缘、PE、断电操作和正确接线。

## 6. 为什么 24V 支路短路未必让 AC 侧空气开关跳闸？

24V 开关电源通常有电子限流/保护。某个电磁阀或传感器支路短路时，开关电源可能先进入限流，导致整个 24V 总线掉压：

```text
24V 某支路短路 → 电源限制输出 → 24V 总线欠压
                  → PLC 重启/传感器失效/其他负载异常
```

若只依赖普通断路器，而电源没有提供足够故障电流，支路断路器可能无法按预期快速脱扣。工业控制柜可能按设计使用**适用 DC 的熔断器、电子分路保护模块（选择性保护）**，隔离故障支路；要核对电源限流特性、保护器参数、导线和负载特性。

## 7. 故障判断与安全界限

| 现象 | 优先思路（不是直接结论） |
|---|---|
| 负载增多后电源掉压 | 核算最大同时电流、启动峰值、温度降额 |
| 某支路故障导致全柜 PLC 重启 | 检查分路保护和开关电源限流行为 |
| 金属外壳疑似带电 | 停用、隔离并由合格人员检查 PE/绝缘/保护装置 |
| 断路器频繁跳闸 | 区分启动浪涌、持续过载、短路、保护选型与故障 |

禁止通过短接 +24V/0V、故意触碰市电、制造漏电或带电拆线来验证保护动作。故障测量、绝缘及保护功能检查必须由具备能力的人员遵循安全规程。
