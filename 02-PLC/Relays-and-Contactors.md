# 继电器与接触器：PLC 小信号如何控制电机动力回路

> P0｜学习中 / 待验证｜2026-11-04。面向 PLC 与 C# 上位机工程师理解控制回路；不是实际电柜接线图。接线、测量、选型和保护整定须以完整型号手册、电气图及合格人员审核为准。

## 1. 一句话理解

**PLC 输出的小电流不是给电机供电，而是给继电器/接触器的线圈供电，线圈产生电磁力，带动另一组触点动作；电机所需的大功率来自独立的主电源回路。**

控制回路负责“发出动作”，主回路负责“提供动力”。二者通过线圈、衔铁和触点的机械联动配合，而不是把 PLC 的 24V 电能放大成电机功率。

## 2. 电磁继电器的基本结构

常见电磁继电器包含：

- **线圈（Coil）**：通电后产生磁场。
- **铁芯/磁路**：集中磁通，增强电磁吸力。
- **衔铁（Armature）**：受到磁力吸引而移动。
- **弹簧**：线圈失电后使机构复位。
- **触点（Contacts）**：随衔铁动作而接通或断开外部回路。

线圈通电 → 产生磁场 → 衔铁运动 → 触点改变状态；线圈断电 → 磁场消失 → 弹簧复位。继电器线圈与触点回路按额定绝缘设计彼此电气隔离，并通过机械结构联动；绝缘等级和允许电压必须看器件规格。

## 3. NO、NC 与线圈端子

- **NO（Normally Open，常开）**：在线圈未励磁/机构未动作的正常状态下断开；继电器吸合后闭合。
- **NC（Normally Closed，常闭）**：在线圈未励磁/机构未动作的正常状态下闭合；继电器吸合后断开。
- **COM**：转换触点的公共端，具体端子编号看器件图。
- **A1/A2**：常见接触器线圈的两个端子；线圈额定电压可能是 24V DC、24V AC、110V AC、220V AC 等，必须与控制电源匹配。部分 DC 线圈有极性或内置抑制器，依标识接线。

NO/NC 描述的是触点在未励磁时的状态，不等于 PLC 梯形图中的常开/常闭逻辑触点；两者属于不同层次。

## 4. 接触器是什么？和普通继电器有什么区别？

接触器（Contactor）也是电磁驱动触点的器件，但主要面向频繁接通/分断电动机等动力负载，通常具有：

- 较大的主触点和适合开断负载的灭弧结构；
- 可用于控制三相电机的多组主触点；
- 辅助 NO/NC 触点，可用于自锁、互锁和状态反馈；
- 按电压、电流及使用类别（例如电机应用常见 AC-3）标定的额定能力。

普通继电器常用于信号、控制和较小负载；接触器面向动力负载。不能只凭外观或“额定电流数字”比较，必须核对负载类别、启动/分断工况、线圈规格、寿命和制造商数据。

常见端子标识（仅为常见约定，具体型号以产品标识为准）：
- 主回路进线：L1、L2、L3；
- 主回路出线：T1、T2、T3（也可能标为 2T1、4T2、6T3）；
- 线圈：A1、A2；
- 辅助触点：常见 13–14 为 NO、21–22 为 NC，但须核对型号。

## 5. PLC 为什么能用小电流控制接触器？

以教学示例为例：PLC 是 24V DC PNP 晶体管输出，接触器线圈是匹配的 24V DC 线圈。概念回路：

```text
控制回路（低压，以下是不同输出类型的概念示意，不能同时照接）：
PNP 晶体管输出：
+24V/L+ ── Q0.0 源型输出 ── A1 [KM 24V DC 线圈] A2 ── 0V/M

NPN 晶体管输出：
+24V/L+ ── A1 [KM 24V DC 线圈] A2 ── Q0.0 漏型输出 ── 0V/M

PLC 继电器输出：
外部 +24V ── Q0.0 的 COM/NO 无源触点 ── A1 [KM 24V DC 线圈] A2 ── 0V

主回路（动力）：
三相电源 L1/L2/L3 ── KM 三组主触点 ── 电机 U/V/W
```

这是功能关系示意，不是完整接线图；真实接线还要有适当的电源保护、公共端、控制回路保护、安全联锁、过载保护和 PE，且必须核对 PLC 输出组接法。

不同输出类型不能混为一谈：

- **PNP 晶体管输出（源型）**：输出导通时向负载提供正电位/电流，负载另一端回到规定的 0V。
- **NPN 晶体管输出（漏型）**：输出导通时把负载回路拉向 0V，负载另一端接规定的 +24V。
- **继电器输出**：Q 端通常是无源触点，不会自行产生 24V；需要外部电源经过触点和线圈构成回路。

线圈只消耗控制电源提供的线圈功率，用来建立电磁力。接触器主触点闭合后，电机从三相动力电源取得能量。**不存在“24V 小电流被放大成 380V 大电流”的过程。**

### 为什么不能随便把线圈接到 PLC 输出？

需同时核对：
1. PLC 输出是 PNP、NPN 还是继电器触点，公共端如何接；
2. 输出点/输出组的额定电压、电流、组总电流和允许负载类型；
3. 接触器线圈的 AC/DC、额定电压、吸合/保持电流和浪涌；
4. 线圈是感性负载，断电时可能产生反向感应电压；按 PLC 和接触器制造商要求选择适当的续流二极管、压敏/RC 抑制器等。内置二极管的 DC 线圈有极性要求；
5. 若线圈电流或浪涌超出 PLC 输出能力，应采用额定匹配的中间继电器/驱动模块，而不是硬接。

## 6. 主触点、辅助触点与反馈

- **主触点**：接通/断开动力回路，承载电机工作电流。
- **辅助触点**：用于控制逻辑、互锁或反馈；常见做法是用一组辅助 NO 触点向 PLC 输入反馈“接触器机构已吸合”。
- 辅助触点闭合不等于电机一定已转动，也不能在未经安全设计时证明主触点没有焊接。若需要验证电机运行，还需合适的驱动器状态、电流、速度或独立传感反馈。

必须区分四层状态：
1. C# 发出启动命令；
2. PLC 逻辑位（例如 Q0.0）变为 1；
3. 物理输出级/控制回路确实使线圈得电，接触器机构吸合；
4. 主回路向电机供电，电机实际运行并产生反馈。

**Q0.0=1 不等于接触器已吸合，更不等于电机已运行。** 上位机应分别显示命令、接触器反馈、驱动器/电机状态，不能把写入成功当作动作完成。

## 7. “Q0.0=1，接触器却不吸合”如何分层分析？

先按现象缩小范围，不要直接认定接触器坏了：

| 观察结果 | 优先检查方向 |
|---|---|
| PLC 程序位为 1，但输出指示/物理输出未动作 | 输出模块状态、输出组电源、公共端、模块诊断、输出类型与额定能力 |
| 输出命令存在，但 A1/A2 无额定电压 | 24V 控制电源、熔断器、联锁触点、接线断路、公共端、输出级 |
| A1/A2 有符合线圈规格的电压，但不吸合 | 线圈 AC/DC/电压是否匹配、线圈是否开路/损坏、机构是否卡滞 |
| 接触器已吸合，但电机不转 | 主回路电源/断路器/过载保护、缺相、主触点、驱动器与电机状态 |

A1/A2 两端测得 0V 时，优先从控制电源和回路查起；它本身不能证明机械机构卡住。带电测量只由具备相应资格的人员按规程执行。不可短接联锁、旁路过载/急停或强制输出试图“让设备动起来”。

## 8. 与自锁、互锁和安全控制的关系

- 接触器辅助 NO 触点可参与传统硬件自锁：启动按钮短暂动作后，辅助触点保持线圈回路。
- 正反转接触器可采用辅助 NC 交叉互锁，必要时有机械互锁，防止两个方向接触器同时吸合。
- PLC 软件互锁、普通接触器辅助触点和 UI 按钮禁用不自动构成安全功能。急停、防护门、危险运动停止等要按风险评估设计适当的安全回路/安全设备。
- 接触器主触点可能磨损或焊接，不能仅凭 PLC 已撤销输出就断言动力已可靠隔离。
