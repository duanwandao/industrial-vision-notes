# PLC 数字量输入：PNP、NPN、COM、光耦与逻辑 0/1

> P0｜学习中 / 待验证｜2026-11-04。适用于**支持相应输入极性**的 24V DC PLC 数字量输入的教学概念；S7-200 SMART 必须按 CPU 完整型号及输入组接线图核对，不能把本笔记当作实机接线图。

## 1. 首先分清五个层次

| 层次 | 示例 | 代表什么 |
|---|---|---|
| 电源 | +24V / 0V | 外部直流供电和参考点 |
| 输入端子 | I0.0、1M/COM | 物理接线位置，输入通道与公共端 |
| 输入检测电路 | 限流、保护、光耦、比较与滤波 | 是否满足「有效输入」条件 |
| 内部数字电平 | 高 / 低（如 3.3V / 0V） | 芯片内部的电压状态，不一定与 I0.0 端子同电压 |
| PLC 逻辑位 | 输入映像区 I0.0 = 1 或 0 | 用户程序读取的布尔状态 |

**最重要的纠错**：`I0.0 = 1` 并不意味着 I0.0 外部端子一定是 +24V；CPU 侧某个引脚为低电平，也不一定表示用户程序输入位为 0。

## 2. 传感器是什么？PNP/NPN 又是什么？

三线制接近传感器（以常见配色为例，仍要核对具体产品）：

- 棕：+24V 电源；蓝：0V；黑：开关信号输出。
- 检测金属工件时，内部输出晶体管按其类型导通。
- **PNP（源型/Sourcing 输出）**：动作时通常把信号端接近 +24V，向接收回路提供电流。
- **NPN（漏型/Sinking 输出）**：动作时通常把信号端拉向 0V，吸收来自接收回路的电流。

PNP/NPN 指输出晶体管的类型或输出方式；「常开/常闭 NO/NC」指未触发时输出动作状态，是**两个独立维度**。线色、端子名称和传感器外观都不足以决定接线。

## 3. COM（Common）/1M 是什么？

PLC 输入通常按组共用公共端，以构成该组输入的电流回路。有些 S7-200 SMART CPU 将输入组公共端标为 `1M`、`2M` 等。**不是所有 COM 天然都是 0V**：

- **PNP 示例**：输入组 COM 接 0V；
- **NPN 示例**：支持该模式的输入组 COM 接 +24V。

须先确认输入组的规格、隔离/双向电路、共用方式，再接线；不同输入组不一定可以任意混接。

## 4. 两条完整电流回路（本课核心）

### PNP 传感器动作，COM 接 0V

```text
+24V → PNP 传感器导通的输出开关 → PLC I0.0
     → PLC 内部输入检测电路 → COM/1M → 0V
```

此时 I0.0 端子对 0V 测量通常接近 +24V（实际取决于负载与压降）；若有效输入条件满足，PLC 逻辑位 I0.0 = 1。

### NPN 传感器动作，COM 接 +24V

```text
+24V → PLC COM/1M → PLC 内部输入检测电路
     → PLC I0.0 → NPN 传感器导通的输出开关 → 0V
```

**为什么 I0.0 端子约 0V，PLC 仍读到 1？**

- 因为 NPN 晶体管导通后，把 I0.0 **拉到接近 0V**；
- 而 COM 仍在 +24V，故输入检测电路**两端存在电压差**、形成有效电流；
- PLC 识别输入电流/电平满足其阈值，再表示成布尔 1。
- **0V 是相对参考点的电位，不等于 0A 电流**。串联稳态电路里电流从检测电路经过 I0.0 再流向 0V，并没有在电阻或 LED 中被「消耗」。

### 什么时候电压下降？

不是“电流沿电线越走越低”，而是**电阻、LED、晶体管等有压降的器件两端存在电位差**。以 0V 作为参考时，流经元件前后的各点电位不同。闭合 NPN 输出会改变整个回路的状态，并将端子拉到低电位；断开时，I0.0 电位由内部电路、泄漏电流等决定，不能一概说必是 24V。

纯教学假设：24V、串联 4.7kΩ、LED 正向压降 1.2V、导通晶体管压降 0.1V：

`I = (24 - 1.2 - 0.1) / 4700 ≈ 4.83mA`

于是电阻约降 22.7V、LED 约降 1.2V、I0.0 端子约 0.1V；通过 I0.0 的电流仍约 4.83mA。**这绝不是 S7-200 SMART 内部真实电阻或输入电流值**。

## 5. 限流电阻与光耦（Optocoupler）

常见的隔离型数字输入可抽象为：

```text
外部 24V 输入 → 保护/限流 → 光耦 LED 发光
                                ║ 光学耦合/电气隔离
                       光敏器件改变导通状态
                                ↓
                         信号调理/逻辑判断
                                ↓
                          CPU 可读状态
```

- 限流电阻限制光耦 LED 的回路电流，保护输入级；不能说电阻“消耗了电流”。
- 光耦内部两侧通过光传信号，常用于电气隔离；具体隔离等级和防护能力以规格为准。
- 对兼容双向输入的模块，需要适合双向信号的输入结构（例如双向光电耦合或等效电路）；**不能拿一颗单向 LED 的教学示意直接推断真实内部设计**。
- 光敏晶体管加上拉电阻可能输出「低电平有效」，内部再取反；原始高/低电平不等于用户程序布尔 1/0。

**高/低电平**：由接收芯片的阈值范围定义，3.3V 数字逻辑与 24V 工业接口的高低阈值不是一回事。低电平不表示一定没有电流。

## 6. 输入滤波与扫描映像

输入经过电气检测与滤波后，CPU 在普通扫描中更新数字量**输入映像区 I**；梯形图 `--| |-- I0.0` 检查逻辑位为 1，`--|/|-- I0.0` 检查逻辑位为 0。

- 电气滤波会抑制较短干扰，但过短脉冲也可能无法被识别；
- 物理短脉冲还可能落在两次普通扫描的输入采样之间；
- 高速信号需根据 CPU、输入点及项目设置，考虑脉冲捕获、高速计数或中断；
- **高电平、PLC 位值、梯形图常开触点、物理 NO/NC 按钮是不同层次**。

## 7. 现场排错顺序（安全的概念检查）

在合格人员和设备文档指导下：确认 CPU 完整型号与输入组 → 核对传感器 PNP/NPN 和 NO/NC → 核对 24V 电源和 COM 极性 → 核对实际信号变化、线缆及接线 → 检查在线输入状态、滤波、扫描/高速功能。**不得不经核对直接改变 COM 接法，更不能向 CPU 芯片引脚加 24V。**
