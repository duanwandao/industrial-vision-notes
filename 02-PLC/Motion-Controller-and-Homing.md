# 运动控制板卡、回零与定位

> P0｜待学习 / 待验证｜2026-11-02。教学示例与实际设备分开，安全功能必须独立设计。

## 运动控制板卡是什么

运动控制板卡（Motion Control Card）是工控机/计算机内的运动控制硬件，或经通信连接的专用运动控制器。它接收上位机通过厂家 SDK/API 发出的运动命令，在实时控制侧完成脉冲/方向输出、轨迹规划、加减速、多轴协调、限位或原点检测等（视型号能力）。板卡的控制信号一般不是电机绕组动力电流；仍需要合适的驱动器。

```text
C# WinForms → 厂家 SDK → 运动控制卡/控制器 → 步进/伺服驱动器 → 电机 → 丝杆与滑台
                         ↑ 原点、限位、部分反馈信号
```

和 `C# → HslCommunication → PLC → 驱动器` 对比，PLC 通常还承担工艺逻辑、I/O 与设备协调。现代带运动功能的 PLC 也能实现复杂插补；**不能一概说“PLC 只能简单运动、板卡一定更高级”**。EtherCAT 是一种常见工业以太网现场总线，既可能用于 PLC，也可能用于工控机运动控制器。区分运动控制**卡**、运动**控制器**、运动控制 **PLC/模块** 以及驱动器。

## 回零：建立机器坐标参考

典型增量式/开环步进轴上电后，控制器的位置计数不一定等于机械实际坐标。回零（Homing）通过原点信号及配置策略建立位置基准；常见过程：快速寻原点 → 停止/退出开关 → 慢速再接近 → 应用零偏移 → 回零完成。**具体过程取决于回零方式与控制器**，未必每种方式都走这五步。

**回零可以中途停止。** 如果 STOP/Abort 取消回零，本次 Home Done 不应当作成功；一般重新回零或通过经确认的其他方式重建坐标。正常受控停止需按设备加减速执行，急停则由符合风险评估的独立安全功能实现；不要把普通 PLC 的 Abort 位直接当安全急停。

## 绝对、相对、点动

| 动作 | 意义 | 是否要求回零 |
|---|---|---|
| 绝对定位 | 到指定机械坐标，例如 200 mm | 一般需要有效机器坐标参考；可能通过回零或其他可信的位置建立方式获得 |
| 相对定位 | 从当前点移动 +50 mm | 计算上无需机械零点；实际设备仍可能因软限位/流程互锁禁止 |
| Jog 点动 | 手动低速持续运动，释放后受控停止 | 依设备策略，通常可用于维护/找原点，但必须有许可与限位 |
| 回零 Homing | 建立机械坐标参考 | 它本身就是建参考的操作 |

**重要例外：** 具备可信绝对值位置反馈并正确保存/校验的系统，不一定每次上电都回零。没有回零却执行绝对定位，可能把控制器计数坐标误认为真实机械位置。

建议 PLC 侧状态机：`Unreferenced → Homing → Referenced → Moving → Done`；故障/Abort 进入相应故障或未建立参考状态。上位机按钮置灰不替代 PLC 侧许可、限位和安全控制。

## 回零握手与监控

把 `HomeStart`（启动请求）、`HomeBusy`（正在执行）、`HomeDone`（成功）与 `HomeError`（失败）区分开。一个 200 ms 的请求脉冲不代表运动只执行 200 ms，更不代表已经完成。短暂上升沿命令需 PLC 正确采样、保持/握手，避免扫描漏检。

## 常见面试回答

- 为什么回零后还会低速再找一次？减小高速触发与停止延迟引起的定位不一致，最终精度还受开关重复精度和机械误差影响。
- 回零中途按 STOP？应受控取消并明确报告未完成；不得保持误导性的 HomeDone。
- 相对运动不回零就完全安全吗？不安全；没有可信坐标就难以执行软限位，仍需硬件限位、安全设计和操作许可。
