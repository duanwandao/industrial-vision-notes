# 三相交流电机、4 极电机、整流器与变频器

> P0｜学习中 / 待验证｜2026-11-04。用于理解普通交流电机与 VFD，和步进/伺服驱动器的电路及控制方式需分开看。

## 1. 什么是 4 极电机？

「极」是**磁极**，4 极指三相定子绕组产生的旋转磁场沿圆周形成四个交替排列的 N、S 磁极，即 **2 对极**；不是四根电源线、四相供电、也不一定安装四块永久磁铁。

常见交流电机的同步转速：

`n_s (r/min) = 120 × f(Hz) / P`（P 是**总极数**，不是极对数）。

| 50Hz 下总极数 | 同步转速 |
|---|---:|
| 2 | 3000 r/min |
| 4 | 1500 r/min |
| 6 | 1000 r/min |
| 8 | 750 r/min |

普通三相**异步**电机的转子转速通常略低于同步转速，差异叫滑差；以上不是实际额定轴转速，必须以铭牌为准。四极电机输入 25Hz 时同步转速约 750 r/min；低频运行能否持续输出所需转矩、是否需要独立风扇，依电机和驱动系统能力。

## 2. 变频器（VFD）与逆变器（Inverter）的关系

- **整流器（Rectifier）**：把交流电 AC 转成直流电 DC。
- **直流母线（DC Link / DC Bus）**：整流和逆变之间公共的直流能量通路，常配电容平滑电压/暂存能量。
- **逆变器（Inverter）**：利用 IGBT/MOSFET 等功率器件快速开关，把直流电转换成按控制策略生成的交流电（输出电压通常为 PWM 脉冲，电机电感使电流相对平滑）。
- **变频器 VFD**：常见结构是整流 → 直流母线 → 逆变 → 电机，并配套控制、检测和保护。逆变器只是其中一个环节。

```text
电网三相 380V 50Hz AC
    ↓ 整流
高压直流母线（滤波电容）
    ↓ 逆变：PWM 调节基波频率、电压/电流
三相交流电机（例如 25Hz）
```

为什么不是直接把电网 380V 送给电机？因为电网频率通常固定（例如 50Hz），**需要调速时应生成频率/电压受控的输出**。先整流再逆变是一种主流、易于控制的电能变换方式；也存在直接 AC-AC 转换拓扑，故不是所有变频设备的唯一物理方案。

## 3. 直流母线不是 24V 控制电源

对于额定三相线电压 380V AC，整流加电容滤波的直流母线电压常在约 `380×√2≈537V` 的量级，会随供电、负载及回馈/制动工况改变；不是恒定 537V，也不是 24V 端子。

直流母线电容可在断电后仍保留致命电压。**不得凭设备断电就触摸母线或自行测量；遵循厂商放电等待、隔离、验电与合格人员规程。**

## 4. 和 PLC/C# 上位机的边界

- C# 上位机发速度目标/启停请求，不直接产生功率驱动波形。
- PLC 按安全许可和逻辑，经通信、数字量或模拟量命令变频器。
- 变频器完成电机电流/电压/频率控制；运动结果还受负载、传动和电机参数影响。
- 步进驱动器的 PUL/DIR 接口与三相异步电机 VFD 输入不是同类接口；不能照搬接线。

## 6. 三相电流、120° 相位与中性线 N

三相交流电的三相电压/电流在理想对称系统中频率相同、幅值相同、相位彼此相差 120°。以三相平衡正弦电流为例：

`i_A=I_m sin(ωt)`
`i_B=I_m sin(ωt−120°)`
`i_C=I_m sin(ωt+120°)`

任意同一时刻，三相瞬时电流的代数和为：

`i_A+i_B+i_C=0`

这里的正负号表示相对于各自参考方向的方向，不是把三个“10A 有效值”当作普通标量直接做加减。若说三相电机每相电流都是 10A，通常指三相电流有效值相等；每一相的瞬时值仍随时间变化。

### 为什么平衡三相负载的 N 线电流为 0？

在理想三相平衡正弦负载中，三相电流的矢量和为零，因此星形负载中性点没有净电流需要经 N 线返回。若负载不平衡，连接的中性线可能承载不平衡电流；非线性负载的三次等三倍频谐波也可能在中性线上叠加，不能把“平衡时 N=0”推广到所有实际配电负载。

### 三相三线电机为什么不需要 N？

普通三相电机的三组定子绕组由 L1/L2/L3 供电，绕组之间形成相间电流回路。常见星形连接的星点可以不引出到外部 N（浮置星点）；三角形连接则由三组绕组首尾构成闭合三角形。**N 不是三相电机正常运行必需的工作导体**。PE 保护地线仍按规范连接电机外壳；PE 不是正常工作回流线，也不能拿来代替 N。

## 7. 缺相（Phase Loss）对三相电机的影响

缺相是三相供电中某一相线路或绕组回路断开/失效。对常见三相异步电机：

- 电机已经运行时发生缺相，可能因转子惯性和剩余相形成的电磁作用而继续转动，但可用转矩下降，电流分布变得不平衡，剩余绕组可能过热。
- 电机在静止状态下缺相，通常不能正常自行启动，可能只发出嗡鸣并产生较大电流；不要反复尝试启动。
- 是否继续转、各相电流多大、多久会过热，取决于电机接法、负载、故障位置和保护装置，不能用单一固定数值概括。

常见保护包括合适整定的电机过载保护、缺相/相不平衡监测或电机保护继电器。不同热过载继电器对缺相的保护能力不同，须核对产品说明与适用标准。**电机仍在转不代表可以继续运行；不得旁路保护装置。**
